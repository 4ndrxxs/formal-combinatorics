# Quadratic signings of the Paley conference matrix

For each prime power (q) congruent to one modulo four, index the matrix by the finite field and a point at infinity. Its finite entries are the quadratic character of the difference of the points. Its border entries are positive and its diagonal is zero. The three positive sets in this check are the nonzero squares together with zero, the nonsquares together with zero, and the finite points where the character of x²−d is negative, for a fixed nonsquare d. Each complement is included. The two possible nonsplit orientations may exchange labels when the field model or d changes.

The file determinants.csv gives 384 exact determinants and Ehlich–Wojtas bounds at the 64 eligible prime powers from 29 through 673. Run the following commands in the directory containing this file.

~~~sh
python check_projective.py
python check_trace.py
uv run --no-project --with python-flint python finite_check.py --jobs 3 --output determinants.csv
~~~

The first standard-library program verifies table coverage, the exact ratio inequalities, and the split symmetries. At q=29 it independently checks all projective sign orbits and the determinants of their representatives. The second program constructs the fields below q=169 by polynomial arithmetic, checks an entire multiplicative cycle, computes each cubic trace both by a signed triangle count and by Hamming distances, and verifies all 108 determinants by integer Bareiss elimination. Append `--output traces.json` to regenerate the replayable small-field record. The FLINT program in the third command reconstructs the full 384-entry table from independent field models.

The first eleven fields, through q=101, cover all orders below the uniform theorem starting at order 110. The other seven fields give a second proof for their six explicit matrices.

The [Lean sources for the 18 fields](certificates/) contain the full matrices as binary rows and six determinant theorems per field. Each theorem has no hypotheses. Its proof checks every row correlation of the full matrix, the permutation putting the positive points first, the entries of the selected principal block, and its exact cubic trace. The four-fifths inequality concerns the determinant of the full completed matrix. For the eleven fields needed below q=109, Lean checks the numbered field coordinates, the full Paley matrix and the diagonal signs against those explicit matrices. At q=49 and q=81, all the finite field axioms are proved for the encoded operations. The uniqueness of finite fields gives the result for every field of the specified size.

To regenerate the sources and replay all 108 determinant proofs, run `python check_lean_traces.py` after `lake exe cache get` in the Lean project. The checker compares the generated code with the distributed source, checks the reported axioms, and runs `leanchecker` on every module. Use `--q 29` for the six proofs at order 30, `--jobs 3` to check three fields concurrently, or `--project PATH` to select a matching pinned Lake installation.

Run `python check_field_models.py --jobs 3` to rebuild the eleven necessary finite certificates, their coordinate interpretations, and the all-order theorem from the distributed sources. `--project PATH` selects the pinned Lake project. The four sets displayed in Theorem 4.1 of Momihara, Suda and Xiang agree with the positive and negative entries of two finite Paley blocks. The mixed block reverses the two signs. Run `python check_msx_core.py` to compare all four incidences for every pair of nonzero square coordinates across the 18 small fields. The Lean theorem `Hadamard.MSXCore.split_core_supports` proves both equivalences over any finite field with the stated square and nonsquare coordinates. For any independent choices of one signed sequence from each column of the four sets, their combined row inner product is q−1 for equal square coordinates y,z and −2−2(−1)ⁱχ(z−y) otherwise. Over all fields the Lean theorem `Hadamard.MSXCore.incidence_gram` proves this formula. The same script checks 169552 literal signed row products at the 18 small fields. For classes (5) and (6) the remaining question is whether their full block layout and border strips realize the hypotheses of the comparison theorem. When both block rows are built from the same pair of cyclic sequences, the sum of the two periodic autocorrelations determines both of those blocks. The connection to the original three classes remains open. Run `python check_split_borders.py --q 5`, `--q 29`, or `--q 49` to check the cyclic block coordinates and every one of the 4096 constant sign borders for each of the two split cores at the selected order. The program computes the full Gram matrix and recovers its two classes. For every accepted border it verifies Gram equality with the reference after permuting and negating its two border rows.
